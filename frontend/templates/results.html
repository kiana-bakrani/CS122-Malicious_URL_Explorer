What do these numbers mean?

Each record represents one reported URL. The same host can have several URL records.

Offline percentage = offline ÷ (online + offline) × 100. Unknown statuses are excluded from this percentage. {% if summary.offline_percentage is none %}No records have a known online/offline status.{% endif %}

Counts describe the saved snapshot, not live availability. Offline does not prove a site is safe.

Online duration is unavailable from a single snapshot. Repeated timestamped status observations are needed to estimate it.

How to read this chart {% if selected_view == 'map' %}

The map compares all countries under the status filter; statistics and CSV summaries remain country-filtered. The logarithmic color scale shows counts: equal color steps represent multiplication, such as 1 → 10 → 100 → 1,000. Gray countries have zero records in this selection; that does not mean they are threat-free. Counts are not adjusted for population or server count, and multiple URLs can share one host.

Hosting country describes server infrastructure, not the attacker's location. A country with no colored records is not necessarily free of threats.

{% else %}

The horizontal axis is the UTC reporting date; the vertical axis is newly reported URLs. These are additions to URLhaus, not the dates attacks began.

The dashed line is a NumPy best-fit line for the total. A positive slope means daily counts tend to rise over this interval; a negative slope means they tend to fall. It is not a forecast.

A straight-line fit can extend below zero. Those fitted values are not negative URL counts.

Zero-count days between the first and last reporting dates are included. The first and last days may cover only part of a day.
